# 资料文件索引

本索引只列出开源仓库实际包含的文件。原始课程资料、客户项目、第三方 PDF/DOCX 和未获授权的案例不包含在仓库中。

| 模块 | 关键文件 | 主要用途 | 自动化节点 |
| --- | --- | --- | --- |
| 根目录手册 | `GEO自动化Skill_实操手册.md` | 以示例客户跑通核心命令 | 全流程演示 |
| 自动化说明 | `docs/GEO实操手册自动化说明.md` | 说明节点、输入、输出与人工把关项 | 全流程参考 |

## 可直接进入表格的字段

| 来源 | 字段 | 建议写入 |
| --- | --- | --- |
| 公司家底 | 公司信息、核心服务、目标客户、资质荣誉、真实案例、核心卖点 | `公司家底六格表` |
| E-E-A-T 模板 | 专业度、经验性、权威性、可信度 | `表一_客户档案` |
| 关键词资料 | 问答词、目标达成词、商业动作词、公式类型 | `表二_关键词库` |
| 文章资料 | 标题模板、文章类型、平台规则、引用来源 | `表三_文章任务` |
| 媒体引用资料 | 来源名、发布时间、核心数据点 | `表三_文章任务` 的引用来源字段 |
| 发布后回查 | 查询词、AI 软件、是否出现目标主体、引用来源、截图 | `表四_监测追踪` |

## 后续可继续自动化

1. 把 Excel 工作簿字段映射到飞书多维表格 API。
2. 把 `geo-keyword-miner` 的 CSV 输出直接写入表二。
3. 把 `geo-platform-adapter` 输出的多平台文件链接写入表三。
4. 把豆包 / DeepSeek / Kimi 查询结果截图和引用来源写入表四。
5. 用 `geo-doubao-research` 生成发布前诊断、发布后检测、前后对比和竞品信源反推报告。
